# Security policy

## Supported version

The newest GitHub prerelease is the only supported public alpha. Older development snapshots may not receive security fixes.

## Reporting a vulnerability

Please use GitHub's private **Report a vulnerability** form in the repository's **Security** tab. Do not open a public issue for a vulnerability that could expose recordings, transcripts, local files or executable paths.

Include the affected version and platform, reproduction steps, impact and any suggested mitigation. Do not include real private recordings; a minimal synthetic fixture is preferred.

Laut executes user-selected local programs and explicitly downloaded, checksum-pinned tools. Reports involving archive extraction, path traversal, project/library boundaries, command invocation, update/download integrity or unintended network transmission are especially useful.
